# Metadata Cache

The `MetadataCache` (`this.app.metadataCache`) maintains in-memory indexes of frontmatter, headings, tags, wikilinks, and backlinks across your vault.

![[metadata-cache-graph-view.png|Graph view nodes and backlinks generated by MetadataCache]]

## Query Note Metadata

Retrieve structured metadata in 0ms without hitting the disk:

```ts
const cache = this.app.metadataCache.getFileCache("Projects/Roadmap.md");

if (cache) {
  // YAML Frontmatter
  console.log(cache.frontmatter?.status);

  // Headings
  for (const h of cache.headings || []) {
    console.log(`H${h.level}: ${h.heading}`);
  }

  // Tags
  for (const t of cache.tags || []) {
    console.log(`Tag: #${t.tag}`);
  }

  // Outgoing Links
  for (const link of cache.links || []) {
    console.log(`Links to: ${link.link}`);
  }
}
```

## Backlinks and Tags

```ts
// All unique tags across vault
const allTags = this.app.metadataCache.getTags();

// Notes with a specific tag
const notes = this.app.metadataCache.getFilesWithTag("#roadmap");

// Notes linking to this file
const backlinks = this.app.metadataCache.getBacklinks("Projects/Roadmap");
```

## Cache Events

Subscribe to cache updates with automatic cleanup:

```ts
this.registerEvent(
  this.app.metadataCache.on("changed", (filePath, meta) => {
    console.log("Metadata updated for:", filePath);
  }),
);
```
