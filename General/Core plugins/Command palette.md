# Command Palette

The Command Palette lets you search and trigger any command in Resin directly from your keyboard, including built-in editor actions, workspace controls, and commands added by plugins.

![[command-palette-modal.png|Command palette with fuzzy search results and hotkey badges]]

## Open the Command Palette

- Press `Ctrl+P` (or `Cmd+P` on macOS).
- Click the terminal icon in the left ribbon.

## Run a Command

1. Open the palette with `Ctrl+P`.
2. Type to filter commands with fuzzy matching.
3. Navigate with the `↑` and `↓` arrow keys.
4. Press `Enter` to run the selected action.

Press `Esc` to close the palette without executing a command.

## Fuzzy Search

The search matches abbreviations, word boundaries, and typos:
- `split` matches **Split Right** and **Split Down**.
- `daily` matches **Open today's daily note**.
- `theme` matches **Switch active theme**.

## Hotkey Badges

Commands with assigned shortcuts display their key combination badge on the right side of the row. You can rebind any command's hotkey in Settings (`Ctrl+,`).
