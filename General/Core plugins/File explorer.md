# File Explorer

The File Explorer is a core plugin that displays your vault file tree in the left sidebar. It lets you organize, create, rename, move, and delete notes and folders directly on your local file system.

---

## Opening the File Explorer

The File Explorer lives in the left sidebar panel.

- Click the folder icon in the left ribbon to toggle the sidebar.
- Click any file in the tree to open it in the active workspace tab.

---

## Creating Files and Folders

You can create new files or folders either in the root directory or inside an existing folder.

### Create a note

1. Click the **New note** button at the top of the file explorer, or right-click any folder and select **New note**.
2. Type the note title in the inline prompt.
3. Press `Enter` to create and open the note.

### Create a folder

1. Click the **New folder** button at the top of the file explorer, or right-click an existing folder and select **New folder**.
2. Type the folder name.
3. Press `Enter` to create the folder.

---

## Renaming Files and Folders

1. Right-click the file or folder you want to rename.
2. Select **Rename** from the context menu, or press `F2` when selected.
3. Type the new name and press `Enter`.

Resin updates the file on disk and keeps open tabs in sync.

---

## Moving Files with Drag and Drop

You can drag any file or folder from the tree and drop it into another folder. Resin updates the file path on disk immediately.

---

## Deleting Files and Folders

1. Right-click the file or folder and select **Delete**, or press `Delete`.
2. A confirmation dialog appears asking to confirm the deletion.
3. Click **Delete** to remove the item from your vault.

If you check **Don't show this again**, future deletions occur immediately without showing the confirmation modal.
