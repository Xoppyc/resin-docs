# File Explorer

The File Explorer displays your vault file hierarchy in the left sidebar, giving you direct control over files and folders on your local disk.

![[file-explorer-sidebar.png|File explorer tree view in the left sidebar]]

## Open the File Explorer

- Click the folder icon in the left ribbon to toggle the sidebar.
- Click any file in the tree to open it in your active workspace tab.

## Create Files and Folders

- **New note**: Click the new note icon at the top of the tree, or right-click any folder and select **New note**. Press `Enter` to confirm.
- **New folder**: Click the new folder icon, or right-click and select **New folder**.

## File Operations

Right-click any item in the file explorer to access file actions:

![[file-context-menu-actions.png|File explorer right-click context menu]]

- **Rename**: Right-click and choose **Rename** (or press `F2`). Open tabs and links update automatically.
- **Move**: Drag and drop files or folders into other directories in the tree.
- **Delete**: Right-click and select **Delete** (or press `Delete`). Resin prompts for confirmation unless silenced in the prompt.
- **System Explorer**: Select **Show in system explorer** to open the parent folder in File Explorer or Finder.
