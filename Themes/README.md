# Theming and Customization (Themes)

Welcome to the **Themes** documentation space. Resin is designed to be deeply customizable through plain CSS stylesheets and design tokens.

---

## Table of Contents

### Theming Guides

- **[[CSS snippets]]**: Quick modular overrides in `.resin/snippets/`, zero-restart reloading, and copy-paste examples.
- **[[Building custom themes]]**: Full theme structure in `.resin/themes/<theme-id>/`, `manifest.json` schema, and starter `theme.css`.
- **[[Fonts and appearance]]**: The 3 font domains (Interface, Text, Monospace) and the native system font specimen picker.
- **[[DevTools inspection]]**: Inspecting elements live with `Ctrl+Shift+I` (or `F12`) to discover class names and test styles.

- **[[Components]]**: Workspace tabs, ribbon, buttons, modals, dialogs, status bar, and context menus.
- **[[Markdown and editor]]**: Headings, code blocks, callouts, tables, wikilinks, and checkboxes.
